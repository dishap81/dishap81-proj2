Open Source GitHub Project Explorer
📌 Project Overview
The Open Source GitHub Project Explorer is a simple web application built using React that fetches and displays trending open-source repositories from GitHub.
It helps users explore popular repositories based on star count using real-time data from the GitHub REST API.
This project was developed as part of my internship task to demonstrate API integration, React fundamentals, and dynamic data rendering.
🎯 Objective
To explore trending GitHub repositories
To understand how to fetch and display data using APIs
To build a basic interactive dashboard using React
🛠 Tools & Technologies Used
React.js – Frontend framework
GitHub REST API – Fetch repository data
JavaScript (ES6)
HTML & CSS
(Note: The project is designed as a basic working prototype and can be extended with charts, filters, and advanced UI features.)
🚀 Features Implemented
Fetches trending repositories from GitHub
Displays repository name and star count
Uses React Hooks (useState, useEffect)
Real-time API data rendering
Simple and clean user interface
